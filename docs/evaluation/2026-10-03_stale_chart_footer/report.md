# 실패한 산점도 요청 아래 과거 히스토그램 표시

2026-10-03. 기존 웹 대화의 마지막 요청은 “전체 데이타에 대해서 age와 balance scatter plot으로 그려줘”였다. 요청은 Ollama ReadTimeout으로 중단했고 차트 생성 도구가 실행되지 않았다. 오류65a8460de89e, 실행c684c749d39c43a6b560031b16cbd903. 원래 실패는 [전체 산점도 미완료 진단](../2026-10-03_scatter_followup/full_scatter_incomplete.json)에 보존돼 있다.

## 원인

UI가 대화 전체를 역순 검색하여 과거의 차트 선택을 찾았다. 최신 턴에 새 이미지/표가 없으면 그 과거 선택을 페이지 맨 아래에 standalone preview로 다시 표시했다. 새 요청이 실패한 경우도 이 조건에 포함되어, 이전의 age 히스토그램이 산점도 요청의 결과처럼 보였다. 모델이 histogram 도구를 골라 새 그림을 생성한 사건이 아니다.

기존 “새 이미지가 있으면 이전 선택 미리보기를 숨김” 규칙은 성공한 턴만 처리하고, 미완료·텍스트 응답·승인 대기 같은 새 턴을 분리하지 못했다.

## 수정

- `ui/analysis_chart_selection.py`: 최신 HumanMessage가 실제 선택 턴인 경우에만 standalone selection을 허용한다. 구조화된 selected_card와 legacy 선택 턴을 지원한다. 최신 요청이 일반 질문이면 더 오래된 선택을 검색하지 않는다.
- `ui/analysis_page.py`: 이전 선택의 이미지는 해당 대화 위치에 보존하고 최신 요청 아래에 복제하지 않는다. 새 시각화에 검증된 산출물이 없는 미완료 상태에는 “이번 시각화 요청은 아직 완료되지 않았습니다. 대화 위쪽의 차트는 이전 요청의 결과입니다.”를 명시한다.
- 데이터·선택·이미지 asset·미완료 checkpoint를 수정하지 않았다. 새 SQL이나 모델 재호출 없이 UI만 갱신했다. 전체 산점도 실행의 부족한 계획 기능을 해결했다고 주장하지 않는다.

## 검증

실패 재현 AppTest에서 과거 선택 → 새 scatter 미완료의 이미지가 2개(과거 대화+오래된 footer)로 표시됐다. 수정 후 과거 대화의 이미지 1개만 남고 stale 제목/복제 이미지는 제거된다. 선택과 incomplete 상태는 유지되고 재실행 후에도 동일하다.

선택/이미지 전달/캐시/그룹 histogram 관련 17 PASS·7 subtests PASS(12.29초). 최종 전체 회귀 697 PASS / 0 FAIL / 4 SKIP·491 subtests PASS(135.02초). [검증 기록](validation.json).

실제 기존 대화를 reload한 결과, 마지막 전체 산점도 요청 바로 아래에 미완료 안내·재개 버튼만 표시되고 age histogram standalone 제목과 이미지가 사라졌다. 과거 차트는 기존 메시지에 남아 있다. [최종 화면](final_web.png).

이번 변경은 UI의 결과 귀속 오류 수정이다. 전체 데이터 산점도는 아직 생성되지 않았으며 범용 agent GO는 미판정이다. 회사 서버 적용/push는 이번 요청에서 수행하지 않았다.
