기존 9/28 고정 평가 4종×3회는 3 PASS / 9 FAIL. 결측 정책의 목표 덮어쓰기, 필터 후 차트 누락, bins=5 요청의 20구간 완료를 공통 계약에서 수정한다.

- 결측 변환은 전처리 정책이며 그룹 평균 목표를 대체하지 않는다.
- 수치 변환 시 그룹 컬럼은 원래 타입/값으로 보존한다. 자동 변환 범위를 넓히지 않는다.
- 변환→명시 조건 필터→집계→차트를 같은 행 계보에서 이어간다.
- 요청한 bins를 저장된 차트 스펙과 비교하고 불일치 차트로 완료하지 않는다.
- 숫자/NULL/조건/그룹/원본 digest 및 matplotlib 막대 빈도에 독립 정답을 둔다.
- 이전 고정 실제 모델 평가를 그대로 재실행하고 모델 호출/결정적 경로를 구분한다. 다른 맥락·고급 SQL 실패를 이 결과로 통과 처리하지 않는다.
