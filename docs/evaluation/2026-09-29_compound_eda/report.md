# 복합 EDA 목표·조건·차트 설정 보존

판정: **이번 고정 복합 EDA의 차단 결함을 수정했다. 전체 범용 agent는 NO-GO 유지.**

## 수정 및 원인

1. `"missing" 문자열만 결측값으로 처리해`가 결측 프로파일 요청으로 분류되어 그룹 평균 목표를 지웠다. 명시적 결측 변환 절을 분석 목표와 분리했다. 별도로 요청한 결측 통계는 계속 프로파일 요청으로 처리한다.
2. 숫자 문자열을 변환한 뒤 필터/그룹/차트 설정이 있으면 로컬 continuation을 중단했다. 검증된 변환본 → 명시 조건 필터 → 집계 → 차트를 같은 데이터 계보에서 이어가도록 했다. 그룹 컬럼은 새 `preserve_columns` 인자로 원래 타입과 값을 보존한다. 추가 보존 컬럼이 있다는 이유만으로 정상 변환본을 거부하지 않는다.
3. `구간 수 5개`는 설정으로 인식되지 않았고, 기본 20구간 차트도 완료로 인정됐다. 요청의 구간 수를 해석하고 실제 렌더 스펙을 차트에 영속 저장한다. 요청과 다른 bins의 실행/완료를 차단하고 지정 값으로 생성한다. 구버전 카드에 스펙이 없으면 맞춤 구간을 만족한다고 추측하지 않는다.
4. 그룹 통계는 요청한 GROUP BY와 출력 그룹 컬럼을 모두 확인한다. 전체 평균을 그룹 평균의 근거로 채택하지 않는다.

`core/analysis_agent/{eda_contract,recovery}.py`, `utils/analysis_{numeric,charts}.py`, 도구 schema와 기존 수치 변환 지시를 함께 변경했다. 기존 prompt를 교체했으며 서로 다른 변환 지시를 추가로 누적하지 않았다. 원격 재조회나 원본 변경은 필요하지 않다.
