# 대화 맥락 전환 수정 및 평가 — 2026-09-29

부분 조건 해제, 설명 후 분석 복귀, 자연어 데이터 전환의 재현 결함을 수정했다. 기존 62개 턴 모두 독립 정답에 일치했다. **범용 agent 출시는 여전히 NO-GO**이며 이번 결과는 정해진 합성 데이터 여정의 검증이다.

## 원인과 변경

- 설명 요청에도 차트·집계 계약이 활성화되고 직전 분석 상태가 덮어써졌다. 검증된 분석 상태를 별도 보존하고 설명 중 분석 도구를 비활성화했다. 재시작 후에도 복귀할 수 있다.
- `조건만 제거`, `앞의 조건은 적용하지 마`가 조건 해제로 해석되지 않았다. 명시된 조건만 제거하며, `해제하지 말고` 같은 부정 표현은 해제로 처리하지 않는다.
- 새 출처를 지정해도 UI에 선택된 이전 데이터가 자동 실행 후보를 제한했다. 검증된 분석 출처를 이어받고, 사용자가 UI 선택을 직접 바꾼 경우에는 그 선택을 우선한다.
- `구간 수만 10개`를 구간 수 변경으로 인식하도록 보강했다. 실제 차트 저장 명세와 요청 구간 수를 검증한다.

테이블·컬럼 이름을 production 코드에 추가하지 않았다. 현재 스키마와 저장된 결과 출처를 사용한다.

## 실제 모델 평가

`scripts/evaluate_conversation_context.py`를 실제 Databricks 모델 설정과 production graph로 실행했다. 이미 로딩된 합성 A/B 데이터만 사용하며 warehouse SQL은 0회다. 자동 실행 가능한 턴은 모델을 호출하지 않는다. 중간 상태 수동 수정·재개는 하지 않았다.

| 평가 | 수정 전 | 수정 후 |
|---|---:|---:|
| 기존 8종 × 2회 턴 정답 | 51/62 | 62/62 |
| 잘못된 완료 | 6 | 0 |
| 원본 보존 | 보존 | 62/62 |
| 기존 여정 전체 판정 | 9/16 PASS | 14 PASS / 2 NOT_EXERCISED |

수정 후 두 요약 여정은 계산 자체가 모두 통과했지만 모델 호출 없이 완료되어 요약이 발생하지 않았다. 이를 요약 검증 PASS로 세지 않았다. 기존 fixture 여정은 그대로 두고, 여섯 번 계산 후 설명 → 분석 복귀 → 조건 해제의 추가 여정을 두 번 실행했다. **추가 18/18턴 통과, 각 실행에서 실제 모델 요약 1회 발생, 원본 18/18 보존**을 확인했다. 따라서 실제 요약 후 복귀 근거는 별도 `summary_results.json`이다.

- 기존 실행: 모델 호출 합계 6, 턴 지연 중앙값 0.026초 / 최대 11.648초.
- 추가 요약 실행: 요약 포함 모델 호출 합계 4, 턴 지연 중앙값 0.029초 / 최대 13.715초.
- 짧은 합성 데이터와 알려진 요청의 결과이므로 일반 성공률 또는 운영 지연 SLO로 해석하지 않는다.

## 실제 웹 확인

재시작한 앱에 합성 A/B 원본만 등록하고, 브라우저 입력창으로 여섯 요청을 제출했다. 두 조건 평균 **20** → score 조건만 해제 **15** → 설명만 수행(도구 0회) → 같은 그룹 최댓값 **20** → B 데이터 전체 평균 **200** → “그 데이터”의 blue 평균 **250**을 화면과 저장된 근거에서 확인했다. 모델 선택은 Databricks이며 로컬 자동 계산에는 모델 호출이 필요하지 않았다. `browser.png`에 화면을 저장했다.
