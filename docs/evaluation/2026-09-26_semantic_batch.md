# 의미 해석·조건부 집계 일괄 수정 검증 — 2026-09-26

## 변경과 근거
질문별 테이블 지식을 코드에 넣지 않고 외부 description → 두 번의 구조화 해석 → 실제 schema/값 정의/기간·측정 차원 검사 → 로컬 계산 → 완료 검증 경로를 추가했다. 기존 조건·선택 원본·snapshot과 context digest를 보존하며 해석만으로 완료 처리하지 않는다. COUNT/AVG의 아직 확인되지 않은 단일 대상에만 적용한다. 설명이 없거나 stale·불일치이면 확인 질문으로 전환한다.

조건부 분포표도 공통 경로로 보강했다. 범주 값 목록이 생략된 metadata 때문에 사용자가 명시한 따옴표 조건을 놓치던 문제가 있었으며, 실제 컬럼에 붙은 명시적 equality를 처리하도록 수정했다. 존재하지 않는 값은 0건으로 계산하고 raw를 보존한다.

## 한계와 다음 작업
**범용 출시 NO-GO 유지.** 동일 모델의 두 해석 합의는 독립 정답 증명이 아니다. 이번 보호 검사는 제한된 COUNT/AVG와 일부 언어 차원이며 모든 모호한 의미를 검증하지 않는다.

1. 실제 운영 TableContext에 신뢰할 수 있는 컬럼 설명을 제공하는 과정이 필요하다. 평가용 설명을 운영 context에 자동 복사하거나 stale 상태를 임의로 갱신하지 않았다.
2. 113문항의 독립 oracle, 새로운 held-out 표현·스키마와 실패 복구 여정을 확대해야 한다.
3. 공식 Spider graph SQL 정확도와 DeepEval 전체 평가는 별도 gate다. 이번 점수를 공식 Spider EX/DeepEval 점수로 표시하지 않는다.
4. 최종 빌드의 신규 승인 로딩·대규모 전송/RSS 검증은 남아 있다. 보유 표본 재사용은 전체 적재 성능의 증거가 아니다. 별도 서버 배포는 범위에서 제외한다.
