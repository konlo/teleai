# 최신행 선택·분포 수정 결과

판정: **로컬 최신행 분포의 이번 acceptance 통과. 범용 agent 출시는 NO-GO 유지.** 이전 실패 0/8 보고서와 원자료는 상위 디렉터리에 그대로 보존했다.

## 변경

- 관찰한 스키마에서 키·정렬·분포 컬럼을 바인딩하는 `analyze_latest_distribution` 도구를 추가했다. 테이블/업무 컬럼명은 production 코드에 고정하지 않았다. 물리적 마지막 행이나 제품별 MAX를 최신행의 대용으로 사용하지 않는다.
- 키별 최신 행의 유일성, 분포 합계, 원본 snapshot/부모 관계와 실제 PNG를 확인해야 완료된다. 시간 기준이 빠지면 확인하며, 최신 시각 동률·결측값에는 임의 선택을 하지 않는다. 시간 기준 답변은 재시작 후에도 원래 요청과 연결한다.
- 파생 데이터의 `row_selection` 계약을 저장·상속한다. 해당 결과를 대상으로 한 후속 SQL은 원본 전체로 자동 확장하지 않는다. 명시적으로 원본 ID를 선택하면 원본 분석은 계속 가능하다.
- 중첩 SELECT/CTE의 출력 alias와 실제 입력 컬럼을 SQL scope로 구분했다. 대소문자 정규화 후 실제 컬럼명으로 되돌린다. 없는 컬럼과 외부 테이블 접근은 여전히 실패한다.
- 명시적 새 조회/다른 출처/추가 통계·표시 설정이 함께 들어오면 지원하는 단일 로컬 작업으로 조용히 축소하여 완료하지 않는다.

독립 정답은 입력 10행에서 5키를 선택하여 **P100=1, P200=3, P300=1**이다. 원본과 최신행·집계 결과를 별도 보존했다. 전체 tests 개수로 agent 성공률을 계산하지 않는다. 이번 warehouse SQL 실행은 **0회**다.

## 아직 해결되지 않은 범위

- 실제 사용자 업무 테이블과 큰 원격 데이터의 latest-per-key SQL pushdown/성능은 이번에 검증하지 않았다. 이 도구는 완전성이 확인된 로컬 행 데이터만 사용한다. 샘플/잘린 데이터로 전체 최신행 분포를 주장하지 않는다.
- 자연어 자동 바인딩은 명시한 단일 키/대상/정렬 기준의 제한된 표현을 지원한다. 임의의 언어·복합 키·시간 컬럼 타입·조건 적용 순서까지 일반화됐다는 근거는 없다. 다중 키와 동률 보조 정렬은 도구 수준에서 지원하며 자연어 후속 연결은 남아 있다.
- 결측 제외/범주 처리, 동률 기준의 후속 대화, 50개 초과 범주 표시, 추가 통계/맞춤 구간의 통합 실행은 아직 확인 또는 추가 구현이 필요하다. 원본은 모두 보존하지만 최신행 파생본은 작업에 필요한 컬럼만 포함한다.
- 기존 대화맥락 실패, 복합 EDA의 목표/설정 누락, 고급 Spider SQL, 미채점 oracle과 DeepEval judge 신뢰도 문제는 이번 결과로 해소되지 않는다.

로컬 서버는 수정본으로 재시작했고 health 200을 확인했다. 별도 서버 운영은 사용자 지시에 따라 범위 밖이다. 이 변경은 아직 커밋·push하지 않았다.
