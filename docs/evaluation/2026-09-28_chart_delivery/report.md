# 차트 생성·전달·표시 검증 보강

2026-09-28. 사용자 보고: histogram 요청 후 실제 막대 이미지 대신 `bar chart ...` 문구가 출력됨.

## 확인한 사실과 진단 범위

현재 로컬 대화에서 보고된 문구와 정확히 일치하는 기록은 발견하지 못했다. 따라서 해당 실행의 단일 원인을 확정하지 않는다. 대신 코드에서 다음 결함과 검증 누락을 확인해 보강했다.

1. 기존 완료 검증은 PNG signature 8바이트만 확인했다. 손상된 PNG나 이미지가 아닌 위장 payload까지 충분히 검사하지 않았다.
2. 최종 답변에는 설명만 들어가고 이미지 연결은 중간 ToolMessage의 cards에 의존했다. 중간 메시지가 없어지면 저장된 차트가 있어도 최종 답변만으로 표시할 수 없었다.
3. 화면은 중간 tool cards를 표시하며 최종 scope 검증에서 받아들인 이미지와 대조하지 않았다.
4. 이미지 파일 생성 테스트와 실제 화면 이미지 요소/로딩 상태 검증이 분리되어 있었다. generic `viz`/`visualize` 요청도 명시적인 시각화 완료 의무에서 빠질 수 있었다.

## 변경

- PNG 전체 디코딩·크기·비어 있는/투명한 이미지 검사를 저장, 완료 판단, 화면 렌더 시점에 적용한다. 최종 출력 시 다시 검사하며 표시 실패를 진단 로그와 화면에 남긴다.
- 최종 assistant 메시지에 검증된 `analysis_artifact_ids`를 저장한다. 중간 도구 메시지가 없어도 최종 답변의 이미지 연결로 그림을 표시한다. 재실행 시 중복 표시는 막는다.
- 완료 응답이 있는 턴에서는 검증된 이미지 ID만 표시한다. 검증에서 거부한 중간 차트는 보여주지 않는다. 기존 기록에는 tool-card fallback을 유지한다.
- histogram 생성은 명시적 `histtype="bar"`로 수행한다. 숫자 bin별 빈도와 실제 Rectangle 막대를 독립 기대값과 비교한다. 여러 작은 열 대신 이미지 본래 크기의 단일 열로 표시한다.
- `viz`/`visualize` 및 ‘분포를 그려’ 요청을 시각화 의무에 포함한다. 이미지가 없는 모델 문장만으로 성공 처리하지 않는다.

## 검증

- 전체 tests 413 PASS, migration 136 PASS. 전체 549개. 별도 강화한 차트 계약 6개 PASS.
- 원문과 같은 `bar chart ...`만 답하는 대역 모델은 이미지 없이 완료하지 못한다. 정상 로컬 복구 경로에서는 실제 히스토그램이 생성된다.
- 손상/시그니처만 있는/빈/투명 이미지 거부, 저장 후 손상 시 완료 차단, 막대 개수·빈도 합계 검사, 최종 첨부만 남은 UI, 재실행·표시 오류 안내, 잘못된 중간 차트 제외를 검사했다.
- 실제 localhost 브라우저: 합성 7행으로 만든 histogram 1개를 확인했다. DOM 이미지 `complete=true`, natural size 660×385, visible width 660. 막대 그림을 직접 확인하고 `browser_histogram.png`에 저장했다.
- 실행 중 대화가 없는 상태에서 앱 재시작. PID 56491, health 200. 코드 교체 중 기존 프로세스의 module cache로 발생한 import 오류도 재시작 후 해소하고 실제 화면을 다시 확인했다.
- 이번 검증은 warehouse SQL/새 업무 데이터 조회 0회. 실제 모델의 모든 시각화 의도나 사용자 원래 환경을 검증했다는 뜻이 아니다. 해당 요청 원문과 환경은 추가 확인이 필요하다. 기존 고급 분석·맥락·최신행 선택의 미완료 과제는 유지한다.
