# 자율 탐색·복구 보강 acceptance — 2026-09-26

사용자의 목표는 새로운 요청에서도 근거를 찾고 도구를 조합·수정하는 agent다. 87문항의 결정적 완료를 일반 자율성으로 대신하지 않는다.

## 이번 공통 작업
1. 등록 도구 검색: 실제 registry에서 schema·역할·관련 skill을 찾는다. 입력값/DB 내용은 지시가 아니며 검색으로 권한을 추가하지 않는다. allowlist 밖 도구는 검색 결과에도 나타나지 않는다. 비용·grain·제약을 알 수 없는 경우 지어내지 않는다.
2. 구조화 복구: 잘못된 SQL/ID/도구 인자를 읽고 재탐색하는 공통 지침. 같은 실행 재시도를 권장하지 않으며 오류가 계산 결과/0건이 되지 않는다. 일부 산출물 완료가 전체 완료가 되지 않는다.
3. 운영 의미 metadata: 기존 저장소·DB metadata 관측으로 의미를 발견하는 경로를 검토한다. 의미 description을 fixture에서 운영에 주입하지 않는다. 신규 SQL은 기존 정확한 승인 계약을 통과해야 한다.
4. 자율성 평가: 합성 미지 schema에서 deterministic rescue를 끄고 실모델로 도구 발견, SQL 오류 수정, 대체 집계, 차트+계산, 재시작 후 후속 요청을 실행한다. 독립 수치·raw digest·조회/승인·이미지 근거를 검사하고 실패도 기록한다.
5. 기존 5개 공식 Spider SQLite 과제의 동일 분모 재평가와 공식 scorer, DeepEval 보조 평가를 실제 trace에 적용한다. 예제모델·정답을 agent에 제공하지 않는다.

## 한계와 완료 정의
권한 없는 신규 Databricks 로딩, 임의 Python을 앱 프로세스에서 실행, 모델의 의미 추측을 정답으로 취급하는 우회는 사용하지 않는다. 미채점 113건과 격리 코드 실행기는 별도 미완료 gate다. 이번 작업은 등록 도구를 사용한 자율 탐색·복구의 증거를 늘리는 것으로, 범용 동등 성능을 선언하지 않는다. 완료 보고는 코드·실모델·회귀·UI/저장 검증·push/CI와 남은 외부 gate를 구분한다.
