# 대용량·보존 요구사항과 검증 경계

2026-09-30. 아래는 전체 계약의 충족 선언이 아니라 실행한 검사와 남은 경계의 매핑이다. production 구현의 보존 검사는 실제 모델 의도 정확도와 분리한다. `tests/`461개와 `migration/`136개 전체 실행에 아래 관련 계약이 포함됐다.

| 요구/여정 | 검증된 근거 | 남은 경계 |
|---|---|---|
| D07 적재 의미·후보 | `tests/test_analysis_load_plan.py`: 실제 source 일치, 조인 source, 잘못된 출처 연결 전 거부, batch 구조/byte/완전성, 원자적 발행 | 고급 다단계 SQL 전체 의미, 실제 모델의 잘못된 기간·지표 해석률 |
| D08 원본·재사용 | `tests/test_analysis_dataset_selection.py`: 부모/raw 복귀, 고유 snapshot registry, 불충분/다른 snapshot 차단, metadata만 탐색. `tests/test_data_preservation_acceptance.py`: 원본 복사·변환·실패·quota·재시작 | 모든 분석 도구의 대용량 부분 scan 보장, 서로 다른 부분 적재의 결합 계획 |
| J21 반복 EDA | 필터/변환/집계/차트/재시작의 도구 계약; 합성100만행 평균→필터평균→원본표본 평균+차트 여정; 이번12행 null→tie→차트 실제 웹 | 한 실모델 대용량 여정에서 임의 변환·복수 차트·원본 복귀 전체 연결 |
| J22 잘못된 재로딩 | 잘못된 source 연결 전 거부, 범위 계약, 최신행 source 전환/조건변경/승인 없는 캐시 전환 방지, 반복 조회0 | 새로운 표현의 실모델 자유계획에서 잘못된 기간·역할 SQL 차단률 |
| J23 실패 후보 | 정상 빈 결과 파일, 뒤 batch schema 불일치, staging quota, 합성100만행 중단/byte초과에서 발행0·선택/원본 보존 | 늦은 결과와 새 요청 revision의 실제 UI 경합, 실제 장치 ENOSPC 장애. quota 검사를 실제 디스크 장애와 동일시하지 않는다. |
| J24 혼합 실행 | raw/aggregate 역할·계보·scope 보존, 원격 집계 뒤 raw 유지, snapshot 모호/불일치 거부 | 전체 통계↔raw EDA↔부분 추가↔sample을 한 실모델 여정에서 검증, 증분 결합 필요성/비용 선택 |

정책 갱신: 사용자가 원격 접근 승인 제거를 요청했으므로 현재 기본은 읽기 전용 자동 실행이다. 과거 설계의 ‘승인 없는 실행0’은 현재 제품 목표가 아니다. SQL 의미·읽기 전용·출처·한도·불확실 제출 재실행 방지·원본 불변은 계속 적용한다. 수동 승인 정책을 명시적으로 켠 경우의 호환성 검사도 유지한다.

현재 실제 Databricks schema 연결이 HTTP400으로 막혔다. 이 외부 차단을 위 독립 구현/평가 공백의 해결 근거로 사용하지 않는다.
