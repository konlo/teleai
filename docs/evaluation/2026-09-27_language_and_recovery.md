# 자연어 이해·추론 복구 보강 — 2026-09-27

**전체 자율 분석 agent 출시는 아직 NO-GO다.** 이번에 확인한 자연어·후속 요청·일시적 모델 장애 경로는 개선됐지만, Codex/Claude Code와 동등한 범용 수행 능력을 검증한 것은 아니다. 별도 서버 배포는 사용자 요청대로 범위에서 제외한다.

## 재현한 문제와 수정

- 새 고정 자연어 세트 10개 여정·12턴의 최초 결과는 7/10이었다. `중위수`는 실제 계산 증거 없이 답했고, `크기순으로 한가운데 오는 값`은 실행 한도로 중단됐다. `10 이상인 것은 제외`는 반대로 `>= 10`을 적용해 정답 3 대신 23.3333을 반환했다. 마지막 오류는 모델 호출 0회로, agent의 조건 해석 결함이다. 초기 결과는 삭제하지 않았다.
- `resolve_analysis_operation` 도구를 추가했다. 기존 규칙이 확정하지 못한 단일 수치 연산을 원문·실제 스키마·고정 필터로 두 번 독립 해석한다. 평균/중앙값/최솟값/최댓값/합계만 지원하며, 해석 일치 후 실제 로컬 계산과 기존 출처·범위·결과 검증을 거쳐야 완료한다. 모델이 새 컬럼·조건·데이터 출처를 추가하지 못한다. 모호함·해석 충돌은 계산 성공으로 처리하지 않는다. 같은 모델의 두 해석이 일치해도 의미 정확성의 증명은 아니므로 별도 정답 평가를 유지한다.
- 후속 요청에서 새 연산의 표현을 못 알아들으면 이전 MAX 등을 그대로 상속하던 경로를 수정했다. 새 조건과 기존 조건, 측정 컬럼과 필터 컬럼을 분리하고, 연산 변경 여부를 확인한 뒤 같은 모집단에 계산한다. 조건만 추가하는 기존 후속 경로는 유지한다.
- 단일 명시 조건의 인접 제외 표현은 반대 비교로 해석한다. NULL이 있으면 반대 비교와 집합 차이가 달라지므로 Parquet footer의 `null_count=0` 증거가 필요하다. 복합 조건 제외·NULL 처리 미확정은 차단한다. 통계를 읽기 위해 원본 행 전체를 복원하지 않는다. 일반적인 부정문 전체를 지원한다는 뜻은 아니다.
- 주 분석 추론과 두 종류의 의미 해석이 같은 영속 모델 호출 복구 기록을 사용한다. 일시적 연결/타임아웃·408/429/일부 5xx만 재시도하고, 401·프로그래밍 오류는 자동 반복하지 않는다. 요청당 자동 재시도 최대 2회, 총 호출/시간 한도, Retry-After 및 재시작 후 cooldown을 유지한다. DB 실행기는 이 재시도 범위 밖이다.
- 실패한 모델 호출/대기 시간도 예산과 진단에 남긴다. 재개할 때 사용자가 자리를 비운 시간을 추론 시간으로 계산하지 않으며, 실패 횟수는 지우지 않는다. 대화 요약과 승인 상태 분류의 직접 모델 호출은 아직 같은 복구 계층으로 통합하지 않았다.
