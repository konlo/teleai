# LLM 행동 선택·관찰·재계획 보강 검증

2026-10-11. Databricks / Ollama `gemma4:e4b`, 별도 검증 대화 `447563e5`.
공식 benchmark 점수·운영 GO가 아닌 지정 기능의 구현 및 실제 브라우저 검증이다.

## 변경

- 확정 목표 이후 실행 후보는 조언이다. LLM이 다음 tool call을 선택하고, 실행 결과를 관찰한 뒤 의존 행동을 다시 선택한다.
- 계획 뒤 자동 조회 덮어쓰기와 모델 예산 소진 뒤 미선택 신규 행동을 LLM 경로에서 제거했다. SQL·범위·원본·receipt·완료 경계는 유지한다.
- 스키마 갱신 의존성을 영구 실패로 차단하던 문제, 발견한 도구 계약의 메뉴 누락, SQL 조회 이유/서식 때문에 정상 계획을 거절하던 문제를 수정했다.
- 행동 입력에서 이전 완료 턴·내부 추론 반복을 줄이되 확정 출처·조건·현재 관측과 원래 checkpoint를 보존한다.
- 원본 수치 histogram의 렌더 도구와 범례/색상 입력 계약을 일치시켰다. 그룹 누적은 지원하지 않는 도구에 넣지 않는다.
- 실행 전 입력/범위 거절도 다음 모델의 관찰로 연결한다. 선택·실행·거절 이력은 분리하고 비공개 사고 과정은 기록하지 않는다.
