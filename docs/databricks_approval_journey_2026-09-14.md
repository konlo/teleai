# Databricks 승인·재사용 실제 검증 — 2026-09-14

## 실제 결과

- 승인 SQL: `SELECT * FROM workspace.default.bank_loan LIMIT 10000`
- 승인 전 원격 실행: 0회
- 승인 후 실행: 1회 성공
- 저장 결과: dataset `99899a9f-699f-49fd-8c47-4806a4da7596`, 10,000행, 18열
- 후속 요청: `현재 로딩된 10,000행 표본의 age 히스토그램을 보여줘`
- 후속 결과: 0.215초, 모델 0회, 원격 0회, `prepare_histogram` 1회, PNG 성공
- 화면 범위: `보유 10,000행 중 10,000행 기준 · unknown`. 전체 모집단 통계로 표시하지 않음

## 발견한 두 결함

1. 사이드바 안내 문구의 `통계`를 실제 통계 계산 요청으로 오인했다. 원격 조회와 저장은 성공했지만 존재하지 않는 계산 증거를 99.123초 동안 기다리고 전체 turn을 125.971초 후 실패 처리했다.
2. `현재 로딩된 10,000행 표본`에서 숫자가 들어간 현재 결과 지정을 놓쳍 불필요한 원격 집계 승인을 제안했다. 해당 제안 2건은 취소했고 실행하지 않았다.

## 수정

- controller가 만든 재조회 요청을 `request_kind=remote_load`로 표시했다.
- 승인된 조회의 저장 dataset을 로딩 요청의 완료 증거로 사용한다.
- 이전 checkpoint에 이미 저장된 성공 결과는 재조회 없이 로컬에서 완료 상태로 재조정한다.
- 숫자가 들어간 `현재 로딩된 N행 표본/샘플`을 `current_result_only` 요청으로 인식한다.
- 현재 결과 히스토그램은 보유 DataFrame으로 결정론적으로 렌더링하며, 원격 조회 제안을 차단한다.
