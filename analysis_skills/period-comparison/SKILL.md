# 기간 비교

이전 대화/결과에서 지표 정의, 모집단, 필터, 집계 단위를 확인한다. 새 발화가 바꾸는 부분만 수정하고 나머지는 유지한다. '같은 조건'을 새 기본값으로 대체하지 않는다.

상대 날짜는 실제 실행 시점과 데이터의 시간대에 따라 해석한다. 월/주 경계와 부분 기간 여부를 기록한다. '이전 달'을 무조건 최근 30일로 바꾸지 않는다. 여러 의미가 가능하고 결과가 달라지면 확인한다.

양쪽 기간에서 다음이 비교 가능한지 확인한다.
- 동일한 지표 식, 단위와 분모.
- 동일한 모집단/그룹 기준과 필터.
- 전체 기간인지 현재까지의 부분 기간인지.
- 표본/잘림/결측 및 데이터 갱신 시점.

필요한 범위가 현재 데이터로 충족되는지 데이터 도구로 검사한다. Databricks 추가 조회는 구체적인 범위와 처리 내용을 제시하고 매번 승인받는다. 승인 기능이 없으면 조회 제안에서 멈추고 도구를 우회하지 않는다.

비교값, 절대 차이, 적절할 때 상대 변화율을 계산한다. 기준값 0이나 비율 해석이 부적절한 값에는 변화율을 억지로 만들지 않는다. 비율 지표의 퍼센트포인트 차이와 상대 변화율을 구분한다. 평균을 결합할 때는 sum/count 등 필요한 통계가 있어야 한다.

표/차트에는 양쪽 기간과 기준을 표시한다. 변화의 관찰만으로 원인을 확정하지 않는다. 결과를 이전 분석에 연결하고 이번에 변경한 조건을 명시한다.
