# 이미지로 차트 추천

최근 대화의 관심 지표와 분석 목적을 유지한다. 사용자가 특정 차트를 명시했으면 적합성을 검사하고 존중한다. 매번 추천 선택부터 다시 시작하지 않는다.

현재 데이터의 coverage와 원본/집계 단위를 먼저 확인한다. 로컬 프로파일에서 타입, 결측, 유효 표본 수, 고유값과 관심 지표를 확인한다. 숫자형 식별자와 상수 컬럼을 측정값 후보로 자동 채택하지 않는다.

유효한 후보 중 질문과 관련 있는 서로 다른 차트를 최대 3개 제안한다. 실제 지원 범위는 아래와 같다.
- 원본 수치 분포: 히스토그램과 한 수치 컬럼의 박스플롯.
- 범주 빈도 또는 기존 집계값 비교: 최대 10개 범주의 막대.
- 시간 변화: datetime 타입의 중복 없는 시간축과 수치 컬럼의 선 그래프. 문자열 날짜의 자동 변환이나 시간 간격 재집계는 이 추천 도구가 수행하지 않는다.
- 두 원본 수치 컬럼의 관계: 산점도. 표시점이 제한되면 카드의 표본 범위를 전달한다.

히스토그램 요청은 prepare_histogram으로 보유 데이터·빈도·이미지를 먼저 재사용한다. 다른 후보는 recommend_chart_images에 현재 dataset ID와 필요한 columns를 전달한다. 이 도구는 적합한 종류를 자체 선택하므로 특정 차트 종류의 생성을 보장하지 않는다. 반환된 카드의 실제 kind와 columns가 사용자 요청에 맞는지 확인한다.

그룹별 박스플롯, 상관 히트맵, 원형 차트, 다중 패널 대시보드는 현재 렌더링 도구에 없다. 해당 이미지를 생성했다고 답하지 않는다. 현재 도구로 계산 가능한 비교 표 또는 기본 차트 후보를 대안으로 설명하며, 사용자가 명시한 형식은 아직 완료되지 않았음을 알린다.

실제 데이터와 사용 가능한 렌더링 도구로 이미지를 만든다. 장식용 생성 이미지나 가상의 차트를 실제 분석 결과로 제시하지 않는다. 집계 결과에서 원본 분포를 추정해 그리지 않는다.

각 카드에 도구가 반환한 제목, 사용 지표, 계산으로 뒷받침되는 추천 이유, 데이터 범위/표본 여부를 붙인다. 선택한 이미지는 해당 카드의 dataset과 실제 PNG를 유지한다. 이미지를 만들 도구가 없으면 생성했다고 주장하지 않는다.

추천을 준비하기 위해 Databricks를 자동 재조회하지 않는다. 추가 데이터가 필요하면 승인 요청을 반환하고 기다린다. 이미지 선택은 재조회 승인이 아니다.

사용자의 선택을 카드·결과 참조로 대화에 남긴다. '중앙값으로'처럼 계산 정의를 바꾸면 기존 범위를 유지한 로컬 계산 결과로 새 후보를 만든다. 현재 도구에는 bin 개수, 색상, 제목, 축, 크기, 차트 종류를 지정하거나 기존 카드를 수정하는 인자가 없다. 이런 편집은 아직 지원하지 않는다고 정확히 안내하고, 필요하면 기존 이미지 또는 새 계산으로 가능한 기본 후보를 제시한다. 편집 지원의 부재를 데이터 부족으로 취급하여 Databricks 재조회를 요청하지 않는다.
