# 이미지로 차트 추천

최근 대화의 관심 지표와 분석 목적을 유지한다. 사용자가 특정 차트를 명시했으면 적합성을 검사하고 존중한다. 매번 추천 선택부터 다시 시작하지 않는다.

현재 데이터의 coverage와 원본/집계 단위를 먼저 확인한다. 로컬 프로파일에서 타입, 결측, 유효 표본 수, 고유값, 사분위수, 시간 범위와 필요한 경우 제한된 수치 쌍의 관계를 확인한다. 숫자형 식별자와 상수 컬럼을 측정값 후보로 자동 채택하지 않는다.

유효한 후보 중 질문과 관련 있는 서로 다른 차트를 최대 3개 제안한다.
- 원본 수치 분포: 히스토그램/박스플롯.
- 범주 빈도 또는 타당한 집계값 비교: 막대.
- 시간 변화: 정렬된 시간축의 선 그래프. 집계 간격과 함수를 표시하고 빈 구간을 임의 연결하지 않는다.
- 원본 그룹 비교: 그룹별 박스플롯과 표본 수.
- 두 수치 관계: 산점도. 여러 수치 관계: 필요한 컬럼만의 상관 히트맵.

실제 데이터와 사용 가능한 렌더링 도구로 이미지를 만든다. 장식용 생성 이미지나 가상의 차트를 실제 분석 결과로 제시하지 않는다. 집계 결과에서 원본 분포를 추정해 그리지 않는다.

각 카드에 목적 제목, 사용 지표, 계산으로 뒷받침되는 추천 이유 한 줄, 데이터 범위/표본 여부를 붙인다. 추천 이미지와 선택 후 차트는 동일 dataset version 및 전처리/config를 사용한다. 이미지를 만들 도구가 없으면 생성했다고 주장하지 않는다.

추천을 준비하기 위해 Databricks를 자동 재조회하지 않는다. 추가 데이터가 필요하면 승인 요청을 반환하고 기다린다. 이미지 선택은 재조회 승인이 아니다.

사용자의 선택을 결과/config 참조로 대화에 남기고 이후 '이걸 모델별로', '중앙값으로' 같은 수정에 연결한다. 확대/색상 변경만으로 데이터를 다시 불러오지 않는다.
