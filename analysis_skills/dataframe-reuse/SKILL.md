# DataFrame 재사용

현재 발화를 이전 분석과 연결해 대상 dataset/result, 유지할 조건, 바꿀 조건을 정한다. '그중'은 참조 결과를 좁히고 '전체로'는 범위를 넓힐 수 있다. 참조가 모호하면 한 가지 핵심 질문으로 확인한다.

사용 가능한 데이터 검사 도구로 출처, 조건, 컬럼, 관측 단위, 완전성, 집계 정의와 조회 시점을 확인한다. 컬럼 존재와 행 수만으로 재사용을 결정하지 않는다. metadata가 없으면 현재 데이터가 요청 모집단을 완전히 포함한다고 주장하지 않는다.

- 완전한 보유 범위 안에서 조건을 좁힐 수 있으면 로컬 변환을 사용한다.
- 기간/모집단 확대, 누락 컬럼 또는 잃어버린 원본 관측값이 필요하면 데이터 요청을 제안한다.
- 표본/LIMIT 결과로 원본 전체의 정확한 통계를 계산하지 않는다. 사용자가 현재 표본 분석을 원하면 그 범위를 명시한다.
- 완전한 빈 결과는 유효한 결과다. 0행이라는 이유만으로 같은 조회를 반복하지 않는다.
- 집계 재사용은 필요한 통계가 보존될 때만 한다. 평균의 단순 평균을 원본 평균으로 취급하지 않는다.

Databricks 재조회는 사용자가 구체적인 조회에 승인한 뒤에만 실행한다. 기존 승인, 스킬 선택, 차트 선택은 새 조회 승인이 아니다. 승인 gate가 제공되지 않으면 재조회 제안까지만 반환한다. SQL/Python 도구로 우회하지 않는다.

사용자에게 재사용/로컬 변환/추가 조회 중 선택한 경로와 이유를 짧게 설명하고 원래 분석 목적을 유지한다. 결과는 새 result ID로 참조해 부모 데이터를 덮어쓰지 않는다. 도구가 ID를 제공하지 않으면 지어내지 말고 연결 기능의 부재를 알린다.
